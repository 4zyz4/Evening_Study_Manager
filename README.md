# 晚自习管理系统

一个基于 Python 和 Web 技术的班级晚自习管理系统，用于记录和管理学生晚自习期间的出入情况。

## 功能特点

- **学生出入管理**：记录学生晚自习期间的出入情况，包括去向、时长和备注信息
- **任务地图**：提供可视化的任务地图，方便查看学生去向
- **统计功能**：统计学生的总任务次数、总任务时长等数据
- **座位管理**：支持交换学生座位功能
- **数据持久化**：使用 JSON 文件存储数据，确保数据不丢失
- **密码保护**：重要操作需要密码验证，保证数据安全

## 系统要求

- Python 3.6 或更高版本
- pywebview 库
- 现代浏览器（用于前端界面）

## 安装步骤

1. 克隆或下载本项目到本地

2. 安装必要的 Python 库：
```bash
pip install pywebview python-dateutil
```

3. 运行项目：
```bash
python main.py
```

## 使用说明

### 主要功能

1. **任务模式**：
   - 点击学生座位，选择去向（语文、数学、英语等）
   - 添加备注信息
   - 记录学生外出

2. **领域模式**：
   - 交换两个学生的座位
   - 调整班级座位布局

3. **存档记录**：
   - 查看学生的历史记录
   - 查看统计数据
   - 查看图表分析

### 数据管理

- 所有数据保存在 `classroom_data.json` 文件中
- 系统会自动保存数据
- 可以手动备份数据文件以防止数据丢失

### 密码设置

- 默认密码：3909618495
- 可在 `main.py` 文件中修改 `PASSWORD` 变量来更改密码

## 常见问题

1. **数据丢失怎么办？**
   - 系统会自动保存数据到 `classroom_data.json` 文件
   - 建议定期备份此文件

2. **如何修改学生名单？**
   - 编辑 `main.py` 文件中的 `DEFAULT_STUDENTS` 列表

3. **如何修改密码？**
   - 编辑 `main.py` 文件中的 `PASSWORD` 变量
